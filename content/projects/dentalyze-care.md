Final-year project addressing observer variability in panoramic radiograph analysis. Engineered an end-to-end clinical support system using a fine-tuned Faster R-CNN (ResNet-50-FPN) model trained on the DENTEX challenge dataset to detect, localize, and classify four dental pathologies. Backed by a FastAPI service with JWT authentication, SQLite storage, and a React interface featuring an interactive bounding-box viewer and PDF report generation.
